# Visual Menu v6

Клиентский **визуальный** скрипт для Roblox: освещение, небо, частицы, трейлы, HUD, радар, скинченджер и конфиги.  
Все эффекты **локальные** — их видите только вы.

> Не чит на урон / aim / wallhack. Только косметика и интерфейс на вашем клиенте.

---

## Возможности

### Интерфейс
- Современное окно: скругления, градиент, тень, бегущий блик
- Поиск по **всем** настройкам (шапка окна или `/`)
- Смена темы перекрашивает весь UI
- Анимации: вкладки, тумблеры, слайдеры, ripple, загрузка
- Сворачивание окна, уведомления, адаптация под маленький экран
- Горячая клавиша по умолчанию: **`K`**

### Мир
- Освещение, атмосфера, bloom, color correction
- Пресеты неба
- Локальные визуальные эффекты окружения

### Персонаж
- Трейл (в т.ч. радужный)
- Аура частиц, Highlight, свечение
- Эффекты: огонь / лёд / сердца / звёзды / тьма
- Орбитальные кольца, afterimage при беге, частицы при прыжке
- Скинченджер: классическая одежда **и** Layered Clothing

### Экран / HUD
- Верхний HUD: ник, пинг, FPS, скорость, онлайн, время сессии
- Мини-радар игроков
- Лимит FPS через `setfpscap` (если поддерживает executor)

### Конфиги
- Сохранение / загрузка настроек
- Автосохранение в `_last` каждые ~8 с
- Автозагрузка при следующем запуске

---

## Установка

1. Откройте любой **executor** (Synapse, Wave, Solara, Xeno и т.п.).
2. Вставьте содержимое `visual.lua`.
3. Нажмите **Execute**.
4. Дождитесь экрана загрузки → меню откроется само.
5. **`K`** — открыть / закрыть меню.

> Скрипт создаёт GUI в `CoreGui`. `ResetOnSpawn = false` — меню не пропадает после смерти.

---

## Управление

| Действие | Клавиша / место |
|----------|------------------|
| Открыть / закрыть меню | `K` (можно сменить в настройках) |
| Поиск настроек | Поле в шапке или `/` |
| Сброс поиска | `Esc` или пустая строка |
| Перетаскивание окна | Заголовок |

## Структура вкладок

| Категория | Содержание |
|-----------|------------|
| **Outfit** | Одежда, аксессуары, скинченджер |
| **World** | Небо, свет, атмосфера, пресеты |
| **Player** | Трейлы, ауры, частицы, FOV, камера |
| **Config** | Сохранение / загрузка / автозагрузка |

Точные названия вкладок внутри меню могут отличаться (МИР · ПЕРСОНАЖ · КОНФИГИ · GUI и др.).

---

## Конфиги

- Ручное сохранение: вкладка **Config** → имя → Save.
- Автосохранение: файл `_last` (примерно раз в 8 секунд).
- При входе подтягивается маркер автозагрузки или `_last`.

Хранение зависит от executor (`writefile` / `readfile`). Без файловой системы конфиги могут не сохраняться между сессиями.

---

## Требования

- Roblox + executor с поддержкой:
  - `gethui` / `CoreGui`
  - по возможности `writefile` / `readfile` (конфиги)
  - по возможности `setfpscap` (лимит FPS)
- Http не обязателен для базовых визуалов

---

## Важно

- Эффекты **только у вас** на клиенте.
- В играх с жёстким античитом любой injected-скрипт может привести к кику — используйте на свой риск.
- Скинченджер учитывает AssetType: классика (`Shirt`/`Pants`) и Layered Clothing (`AddAccessory`).
- Пинг **нельзя** изменить скриптом — это сеть. В HUD показывается реальный пинг.
